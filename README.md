# Brilliant-Bites-Dental - Dental Practice Website

A responsive, professional static website for a dental clinic built with HTML, CSS, and JavaScript. The site provides patients with an intuitive interface to explore dental services, view clinic facilities, locate the practice, and get in touch.

## Live Preview & Demo
- **Live Site:** `http://brilliantbitesdental.com` 
- **Repository:** `https://github.com/code-by-dre/brilliant-bites-dental`

---

## Features

- **Multi-Page Architecture** — Includes dedicated, easily navigable pages for Home, About, Services, Contact, and Location mapping.
- **Service Showcases** — Visual galleries highlighting core procedures like Cleanings, Fillings, Extractions, Dentures, Bridges, and Teeth Whitening.
- **Responsive Layout** — Custom CSS (`style.css`) ensures optimal viewing across desktop, tablet, and mobile screens.
- **Professional Branding** — Integrated high-quality clinic photography (reception and chair views), custom logos, and cross-platform PWA favicons.
- **Static Hosting Ready** — Includes a `CNAME` file for instant, seamless deployment to GitHub Pages using a custom domain.

## Project Structure

```text
dental-website/
├── HTML Pages
│   ├── index.html               # Main landing page
│   ├── about.html               # Practice history and staff details
│   ├── services.html            # Dental procedure information
│   ├── contact.html             # Contact forms and details
│   └── find_us.html             # Interactive location and directions
├── Styles & Config
│   ├── style.css                # Global stylesheet
│   └── CNAME                    # Custom domain mapping
└── Media Assets
    ├── Clinical Photos          # chair_view.jpeg, rep_view.jpeg, chair.webp
    ├── Service Images           # Bridge.jpg, Cleaning.jpg, Denture.jpg, Filling.jpg, etc.
    ├── Brand Assets             # logo.png, name_and_logo.png
    └── Icons & Manifest         # favicon.ico, apple-touch-icon, site.webmanifest
```
